# Astha Yoga & Nature Cure Hospital: website

Demo-only website concept (no appointments or registrations are sent) for Astha Yoga & Nature Cure Hospital, Rohtak, Haryana (since 1995).

Live: see the Vercel deployment linked on the repo.

## What is on it
- Hero, why choose us, 8 therapies (yoga, acupressure, steam bath, hydro therapy, Ceragem, magnet, Sujok, chromo and veins), conditions treated
- Upcoming free camp section with live countdown (sample camp, invented for the demo)
- Appointment request form with validation and a clear success state. No backend: nothing is sent or stored. The real number to book is shown.
- Timings, address, phone, email, map link

## Real vs sample content
Real (from the hospital's public listing): name, established 1995, therapies, conditions, timings, address, phone, email. Sample: the camp, the booking confirmation, therapy descriptions (general explanations written for the demo).

## Stack
Next.js 16, TypeScript, Tailwind 4. No images to download: all graphics are inline SVG and CSS animation (respects reduced-motion). Free hosting on Vercel.

## Run
```
npm install
npm run dev
npm test
```
